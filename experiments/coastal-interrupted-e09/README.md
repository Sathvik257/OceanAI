# Preserved coastal checkpoint

This directory was moved aside before a mistakenly duplicated factory created a replacement output directory. It contains a contiguous prefix of 67 actual model responses and the frozen evaluation suite. The final coastal run uses these responses only when its outgoing requests match exactly; subsequent answers and judgments are new local inference. This is an incomplete checkpoint, not a second completed demonstration.

The label reflects the then-assumed interruption. An unrestricted process check subsequently showed that the earlier factory had still been running. Both overlapping factory processes were stopped; their potentially mixed output is separately quarantined under `experiments/coastal-duplicate-process-audit/`.
